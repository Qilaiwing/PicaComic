# v4.3.0-miuix

> 这是一次较大的更新。自本版本起版本号不再带数字后缀（旧：v4.2.12-miuix1 → 新：v4.3.0-miuix）。

## 新功能
- **漫画源与账号合并**：漫画源管理与账号登录合并为同一页面，一处管理。
- **从仓库添加漫画源**：新增「添加漫画源」弹窗，可直接从本分支漫画源仓库（index.json）挑选安装。
- **连通性检测**：漫画源页新增检测卡片，各源显示延迟胶囊（快 / 慢 / 失败一目了然）。
- **JS 漫画源**：新增 拷贝漫画、包子漫画、漫画柜、MangaDex 源；JS 源不再随应用内置，改为按需从仓库安装。
- **JS 网页登录**：JS 漫画源支持通过内置网页登录并自动识别登录状态。
- **漫画源评论**：支持的 JS 源可查看评论；单章节漫画支持预览。
- **阅读统计**：我的页新增「今日阅读」时长，点按打开阅读统计页。
- **更新日志**：检查更新弹窗直接显示新版本更新日志；关于页新增「更新日志」入口。
- **毛玻璃开关**：关闭后顶栏与吸顶区域改为不透明纯色底，更省电。
- **屏幕刷新率**：跟随系统 / 高刷 / 60Hz，替代旧的高刷开关。
- **备份补全**：备份 / 恢复包含更多设置项与搜索历史等数据。

## 界面优化
- **漫画详情页**：信息改为卡片布局，新增「作品简介」「章节目录」分区与折叠，评分与相关推荐展示优化。
- **评论页**：评论改为卡片样式，输入框悬浮于底部。
- **阅读器**：顶栏显示当前章节。
- **设置页**：全面按 Miuix 风格统一（开关、滑条、弹窗、分组）。
- **漫画块大小**：滑条范围扩大到 60%–140%（1% 步进），手机上可调成 3 列；网格两侧增加边距。
- **顶栏标签**：胶囊样式，未选中时提高文字与底色对比度。
- **分页栏**：改为全宽 2:3:2 布局，修复文字被截断，并为底部悬浮导航栏留出空间。
- **关于页**：重新设计，头部卡片随内容自适应。
- **下载弹窗**：底部改为「全选 / 全不选」与「下载」彩色按钮，与章节列表留出间距。
- **WebDAV 设置弹窗**：重做布局。
- **翻译**：补全繁体中文与英文翻译。

## 性能
- 降低模糊半径，减少不必要的重绘与定时器频率，改善掉帧与耗电。
- 正式版启用 R8 代码压缩与资源压缩，安装包体积更小。

## 修复
- PicACG 自动打卡失效。
- 连通性检测卡片显示原始代码 / 报错文本。
- 头像与历史记录封面变成方形。
- 大字体下统计块溢出、检测按钮文字溢出。
- 设置中重复的「检查更新」入口。
- 拷贝漫画登录地址与请求体错误。

## 其他

- 清理无用代码、资源与依赖。
- 许可证、字体等链接指向 miuix 分支；README 重写；内置 flutter_miuix（Apache-2.0）并注明来源与修改。
