# HyperOS 4 / Glass (opt-in)

Port baseline: upstream feat/miuix-glass at 3f7debbf (2026-09-06). Existing widgets retain their default appearance. Import package:flutter_miuix/miuix.dart and opt into the new components.

## Version check and reading order

The OS4 APIs ship in flutter_miuix **1.2.0** and later; 1.1.x and earlier do not export them.
Check the version the application's `pubspec.lock` actually resolves and that package's `lib/miuix.dart` before using `MiuixGlass*` or `MiuixIcons.os4`.
If they are missing, state the version gap (`^1.2.0` is required) and let the user decide whether to upgrade — never edit `pubspec.yaml` silently.

Read only the relevant sections: [API quick reference](#api-quick-reference), [rendering](#rendering),
[navigation and tabs](#navigation-and-tabs), [complete example](#complete-wiring-example), [popups](#popups),
[existing menus and icons](#existing-menus-and-icons). Original APIs are in [navigation](30_navigation.en.md),
[overlays](40_overlays.en.md), [blur](80_blur.en.md) and [icons](90_icons.en.md).

## Components

- MiuixBlurTopAppBar: collapsing large-title blur (12 logical pixels by default) and titleAlpha.
- MiuixGlassTopAppBar / MiuixGlassIconButton: coordinated material visibility, parent/child material sampling and spring press feedback.
- MiuixGlassNavigationBar / MiuixGlassNavigationItem: floating navigation, drag selection and independently sprung indicator edges.
- MiuixGlassTabRow: separate pills; MiuixGlassSegmentedTabRow: a joined track with a sliding indicator.
- MiuixGlassPopup / MiuixGlassPopupItem: anchored menu and rows.
- MiuixGlassTransformPopup: button-to-panel morph; MiuixGlassSecondaryPopup: row-to-submenu expansion.
- MiuixGlassDropdownPopup: two-spring arc opening for settings choices.
- MiuixGlassDialog: centered glass dialog with scrim and reversible transitions.

Search remains an example. No GlassBottomSheet is exported because the upstream checkout does not implement one.

## API quick reference

Use Flutter parameter names, not Kotlin's `onClick`, positional arguments or alpha-provider lambdas.

| Component | Required parameters / controlled state | Important optional parameters and differences |
|---|---|---|
| `MiuixBlurTopAppBar` | `title` | Original top-bar interface, plus `largeTitleBlurRadius: 12` and `titleAlpha: 1` (double, not a function) |
| `MiuixGlassTopAppBar` | `title` | `backdrop`, `scrollBehavior`, `isContentScrolled`, `navigationIcon`, `actions: List<Widget>`, `bottomContent`; button size 44, title blur 12 |
| `MiuixGlassIconButton` | `onPressed: VoidCallback?`, `child` | `anchor`, `size`, `shape`, `surfaceAlpha`, `tooltip`, `semanticLabel`; null callback disables it, no `enabled` parameter |
| `MiuixGlassNavigationBar` | `items: List<MiuixGlassNavigationItem>`, `selectedIndex`, `onSelect` | `backdrop`, `visible: true`, `height: 54`; not the old `children` API or 2..5-item assertion |
| `MiuixGlassNavigationItem` | `icon: Widget` | `label`, `contentDescription`; wrap vector data with `MiuixIcon(vector: ...)` |
| `MiuixGlassTabRow` | `tabs: List<String>`, `selectedIndex`, `onSelect: ValueChanged<int>?` | `backdrop`, `surfaceAlpha: 1`, `height: 40`, `tabGap: 12`, `colors`; null callback disables selection |
| `MiuixGlassSegmentedTabRow` | Same required parameters | `height: 40`, `trackColor`, `indicatorColor`, `selectedContentColor`, `contentColor`; no `colors` or `tabGap` parameter |
| `MiuixGlassPopup` | `show`, `onDismissRequest`, `child`, plus `anchor` or `anchorBounds` | Ordinary corner reveal; no Kotlin `secondary` flag—use the separate component |
| `MiuixGlassTransformPopup` | `show`, `onDismissRequest`, `child`, `anchor`, `anchorContent: Widget` | `simplified`, `stacked`, `maskColor`, `gap`; `anchorBounds` cannot replace the required anchor |
| `MiuixGlassSecondaryPopup` | `show`, `onDismissRequest`, `child`, plus `anchor` or `anchorBounds` | `materialAnchor` shares the primary material; freeze row bounds before the primary shrinks |
| `MiuixGlassDropdownPopup` | `show`, `onDismissRequest`, `child`, plus `anchor` or `anchorBounds` | Arc opening for settings rows; use `MiuixGlassPopupItem(selected: ...)` for selection |
| `MiuixGlassPopupItem` | `text`, `onPressed: VoidCallback?` | `icon: Widget?`, `summary`, `enabled`, `selected`, `showArrow`, `arrowRotation` in degrees; not `MiuixDropdownItem(onClick: ...)` |
| `MiuixGlassDialog` | `visible`, `onDismissRequest`, `child` | Not `show/content`; radius 28, max width 420, safe margin 24; optional `scrimAlpha` |

All four Glass Popup variants accept `backdrop`, `sizing`, `visuals`, `cornerRadius`, `contentPadding`,
`onDismissFinished` and `onMeasured: ValueChanged<Size>?`. Dialogs accept the styling/sizing options and dismissal callback, but no anchor or `onMeasured` parameter.

- `MiuixGlassPopupSizing(minWidth: 200, maxWidth: 288, maxHeight: 416, safeMargin: 12)` is further constrained by safe areas/keyboard. Do not pass `maxHeight` directly to a Glass Popup.
- `MiuixGlassPopupVisuals` accepts `style`, `material`, `containerColor`, `alpha`, `stroke`, `showStroke` and `shadow`.
  A null stroke selects the default; **use `showStroke: false` to disable it**. Null shadow disables the shadow. Dialog defaults disable the stroke and do not add a menu MaterialToken to the refractive style.
- `MiuixGlass` / `MiuixGlassPanel` require `child`. Common options are `backdrop`, `style`, `material`,
  `shape`, `alpha`, `fill`, `stroke`, `shadow`, `shading` and `enabled`. Shape must be
  `MiuixGlassShape(cornerRadius: 24, smoothing: 1, borderRadius: ...)`, not an arbitrary ShapeBorder.
- Use `MiuixGlassDefaults.style(context)` for a theme-resolved style; `MiuixGlassMaterials.puredThinGlass(isDark)` / `popupViewGlass(isDark)` take a bool, not a BuildContext.
- Popup content already scrolls. Prefer `Column(mainAxisSize: MainAxisSize.min, children: ...)`; do not place Expanded/Spacer in unbounded height.
  Tabs/navigation require bounded width; inside a Row, use Expanded or SizedBox.

## Rendering

MiuixGlass and MiuixGlassPanel sample a MiuixBackdrop. Place MiuixLayerBackdropCapture around the background **only**, then render the glass as a sibling. Capturing a surface that samples that same capture creates a feedback loop.

~~~dart
final backdrop = MiuixLayerBackdrop(); // Keep in State; dispose when finished.

Stack(children: [
  Positioned.fill(child: MiuixLayerBackdropCapture(
    backdrop: backdrop,
    child: const ColoredBox(color: Color(0xFF687AC8)),
  )),
  Center(child: SizedBox(width: 240, height: 140,
    child: MiuixGlassPanel(
      backdrop: backdrop,
      style: MiuixGlassStyles.commonSmallThin,
      shape: const MiuixGlassShape(cornerRadius: 32),
      child: const Center(child: Text('OS4 Glass')),
    ),
  )),
])
~~~

The 35 GlassStyles presets retain upstream values. GlassMaterial describes a blur radius and up to three color layers with nine blend modes. Bars/menus use shading:false; refractive controls use GlassStyle shading. The renderer uses six generated GLSL shaders, low-resolution backdrop processing and full-resolution masks, lighting and shadows. Programs are shared; per-surface shaders and cached images are disposed with their render objects.

No backdrop, no available snapshot or an unsupported shader backend falls back to a solid surface. Captures may lag the source by one frame; this is not native platform-window blur. Optionally await MiuixGlassRendering.load() before displaying the first glass surface. No new dependency is required.

## Navigation and tabs

Use the existing MiuixScrollBehaviorListener(behavior: behavior, child: ...) with the top bar's scrollBehavior. Prefer an explicit isContentScrolled signal derived from the list offset; listen to the ScrollController and rebuild when the top/non-top state changes, rather than reading offset only once. Material must disappear at the page top even when the large title remains collapsed. Top-bar buttons/tabs inherit the effective parent-plus-child blur and share the material transition.

Separate tabs default to height 40 and gap 12; use neutralColors with height 35. Joined tabs use height 40, track padding 3 and gap 8. surfaceAlpha crossfades resting fill to material. Navigation has a minimum height of 54 and supports wrapped captions and RTL. The trailing-edge drag cap is 60 **physical pixels**. Selection is controlled through selectedIndex/onSelect. Reduced-motion preferences are honored.

## Complete wiring example

This can be used as `main.dart` against a version exporting the OS4 APIs. Only the list is captured; the top/bottom bars and popups are outside that subtree. Controllers and anchors live in State and are disposed with it. Dispose the owned `behavior.state`, not the behavior itself. Replace the independent tabs with `MiuixGlassSegmentedTabRow` only after removing independent-tab-only options.

The menu uses `onDismissFinished` to open the dialog after its exit, avoiding competing focus scopes.

~~~dart
import 'package:flutter/material.dart';
import 'package:flutter_miuix/miuix.dart';

void main() => runApp(
  MiuixSystemTheme(
    child: Builder(
      builder: (context) {
        final theme = MiuixTheme.of(context);
        return MaterialApp(
          theme: ThemeData(
            brightness: theme.brightness,
            colorScheme: ColorScheme.fromSeed(
              seedColor: theme.colors.primary,
              brightness: theme.brightness,
            ),
          ),
          home: const Os4SkillDemo(),
        );
      },
    ),
  ),
);

class Os4SkillDemo extends StatefulWidget {
  const Os4SkillDemo({super.key});
  @override
  State<Os4SkillDemo> createState() => _Os4SkillDemoState();
}

class _Os4SkillDemoState extends State<Os4SkillDemo> {
  final _backdrop = MiuixLayerBackdrop();
  final _scroll = ScrollController();
  final _behavior = MiuixExitUntilCollapsedScrollBehavior();
  final _menuAnchor = MiuixGlassPopupAnchor();
  bool _scrolled = false, _menuOpen = false, _dialogOpen = false;
  bool _openDialogAfterMenu = false;
  int _tab = 0, _destination = 0;

  @override
  void initState() {
    super.initState();
    _scroll.addListener(_updateOverlap);
  }

  void _updateOverlap() {
    final scrolled = _scroll.hasClients && _scroll.offset > 0;
    if (scrolled != _scrolled) setState(() => _scrolled = scrolled);
  }

  @override
  void dispose() {
    _scroll.removeListener(_updateOverlap);
    _scroll.dispose();
    _behavior.state.dispose();
    _menuAnchor.dispose();
    _backdrop.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final colors = MiuixTheme.of(context).colors;
    return Material(
      color: colors.surface,
      child: Stack(
        children: [
          MiuixScaffold(
            topBar: MiuixGlassTopAppBar(
              title: 'OS4 demo',
              backdrop: _backdrop,
              scrollBehavior: _behavior,
              isContentScrolled: _scrolled,
              actions: [
                MiuixGlassIconButton(
                  anchor: _menuAnchor,
                  onPressed: () => setState(() => _menuOpen = true),
                  tooltip: 'Open menu',
                  child: const Icon(Icons.more_horiz),
                ),
              ],
              bottomContent: Padding(
                padding: const EdgeInsets.all(12),
                child: MiuixGlassTabRow(
                  tabs: const ['Overview', 'Details'],
                  selectedIndex: _tab,
                  onSelect: (i) => setState(() => _tab = i),
                ),
              ),
            ),
            bottomBar: SafeArea(
              top: false,
              child: Padding(
                padding: const EdgeInsets.all(12),
                child: MiuixGlassNavigationBar(
                  backdrop: _backdrop,
                  selectedIndex: _destination,
                  onSelect: (i) => setState(() => _destination = i),
                  items: [
                    const MiuixGlassNavigationItem(
                      icon: Icon(Icons.home_outlined),
                      label: 'Home',
                    ),
                    MiuixGlassNavigationItem(
                      icon: MiuixIcon(vector: MiuixIcons.os4.settings),
                      label: 'Settings',
                    ),
                  ],
                ),
              ),
            ),
            content: (padding) => MiuixLayerBackdropCapture(
              backdrop: _backdrop,
              child: ColoredBox(
                color: colors.surface,
                child: MiuixScrollBehaviorListener(
                  behavior: _behavior,
                  child: ListView(
                    controller: _scroll,
                    padding: padding,
                    children: [
                      MiuixText('Tab $_tab / Destination $_destination'),
                      for (var i = 0; i < 30; i++)
                        Padding(
                          padding: const EdgeInsets.all(16),
                          child: MiuixText('Row $i'),
                        ),
                    ],
                  ),
                ),
              ),
            ),
          ),
          MiuixGlassTransformPopup(
            show: _menuOpen,
            anchor: _menuAnchor,
            backdrop: _backdrop,
            simplified: true,
            anchorContent: const Center(child: Icon(Icons.more_horiz)),
            onDismissRequest: () => setState(() => _menuOpen = false),
            onDismissFinished: () {
              if (!mounted || !_openDialogAfterMenu) return;
              setState(() {
                _openDialogAfterMenu = false;
                _dialogOpen = true;
              });
            },
            child: MiuixGlassPopupItem(
              text: 'About OS4',
              onPressed: () => setState(() {
                _openDialogAfterMenu = true;
                _menuOpen = false;
              }),
            ),
          ),
          MiuixGlassDialog(
            visible: _dialogOpen,
            backdrop: _backdrop,
            onDismissRequest: () => setState(() => _dialogOpen = false),
            child: Column(
              mainAxisSize: MainAxisSize.min,
              children: [
                const MiuixText(
                  'Opt-in glass; original widgets are unchanged.',
                ),
                MiuixButton(
                  onPressed: () => setState(() => _dialogOpen = false),
                  child: const Text('Close'),
                ),
              ],
            ),
          ),
        ],
      ),
    );
  }
}
~~~

## Popups

Keep popup widgets mounted and change show (visible for dialogs), including during exit. Bind a MiuixGlassPopupAnchor either through a GlassIconButton's anchor property or through MiuixGlassAnchor, not both. anchorBounds, when supplied directly, is in global window coordinates.

~~~dart
final anchor = MiuixGlassPopupAnchor(); // Dispose in State.dispose().

MiuixGlassIconButton(
  anchor: anchor,
  onPressed: () => setState(() => menuOpen = true),
  child: const Icon(Icons.more_horiz),
)

MiuixGlassTransformPopup(
  show: menuOpen,
  anchor: anchor,
  backdrop: backdrop,
  simplified: true,
  anchorContent: const Center(child: Icon(Icons.more_horiz)),
  onDismissRequest: () => setState(() => menuOpen = false),
  child: MiuixGlassPopupItem(
    text: 'Create',
    onPressed: () => setState(() => menuOpen = false),
  ),
)
~~~

Do not reuse GlobalKeys in anchorContent. Before setting the primary popup's stacked flag, freeze the submenu trigger's bounds; pass the primary anchor as materialAnchor to share its material. To blur the primary panel beneath the secondary, supply a separate backdrop capturing the primary but not the secondary.

Defaults: width 200–288, max height 416, safe margin 12 and radius 24. Insets/keyboard further constrain the panel and long content scrolls. Escape, route Back and predictive Back cancellation/completion are supported. Closing disables row activation; cleanup restores touch access, focus and anchor visibility. Dialogs use radius 28 and a light/dark scrim of 0.3/0.6. Set MiuixGlassPopupVisuals(showStroke:false) to disable the rim.

## Existing menus and icons

The Overlay/Window CascadingListPopup and IconCascadingDropdownMenu variants accept:

~~~dart
surfaceBuilder: miuixGlassSurface(backdrop: backdrop),
~~~

This changes the surface only; old geometry/motion remain unchanged. Use the new Glass popups for OS4 opening motion.

MiuixIcons.os4 exposes 176 symbols in the existing five MiuixIconWeight weights. Use MiuixIcons.os4.search or MiuixIcons.os4.byName('settings', MiuixIconWeight.medium). Closed subpaths, glyph offsets and directional RTL mirroring are preserved. Existing basic/extended icons are unchanged.
