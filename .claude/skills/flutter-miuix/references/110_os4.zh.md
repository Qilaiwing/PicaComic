# HyperOS 4 / Glass（可选）

基于上游 `feat/miuix-glass` 分支的 `3f7debbf`（2026-09-06）。OS4 与旧组件并存；导入 `package:flutter_miuix/miuix.dart` 后按需使用，不需要更换主题，也不会把原界面自动改成玻璃样式。

## 版本与阅读顺序

OS4 自 flutter_miuix **1.2.0** 起随包发布，1.1.x 及更早版本不含这些导出。使用前先核对应用的
`pubspec.lock` 实际解析到的版本与该包的 `lib/miuix.dart`：缺少 `MiuixGlass*` / `MiuixIcons.os4` 时，
先说明版本缺口（需 `^1.2.0`），再由用户决定是否升级依赖，不要静默改动 `pubspec.yaml`。

按需读取：[关键参数](#关键参数速查)、[背景采样](#背景采样重要)、[顶栏与导航](#顶栏标签导航)、
[完整示例](#完整接线示例)、[弹窗锚点](#按钮变形成菜单)、[旧菜单接入](#旧菜单接入)、[图标](#图标)。
原组件的参数见 [导航](30_navigation.zh.md)、[浮层](40_overlays.zh.md)；原模糊/高光基础见 [80_blur](80_blur.zh.md)。

## 关键参数速查

以下为 Flutter 公开 API，不照搬 Kotlin 的 `onClick`、lambda alpha 或位置参数。

| 组件 | 必填 / 状态入口 | 常用可选参数与区别 |
|---|---|---|
| `MiuixBlurTopAppBar` | `title` | 继承原顶栏接口；`largeTitleBlurRadius: 12`、`titleAlpha: 1`；`titleAlpha` 是 double，不是函数 |
| `MiuixGlassTopAppBar` | `title` | `backdrop`、`scrollBehavior`、`isContentScrolled`、`navigationIcon`、`actions: List<Widget>`、`bottomContent`；按钮默认 44，标题模糊 12 |
| `MiuixGlassIconButton` | `onPressed: VoidCallback?`、`child` | `anchor`、`size`、`shape`、`surfaceAlpha`、`tooltip`、`semanticLabel`；`onPressed: null` 禁用，不传 `enabled` |
| `MiuixGlassNavigationBar` | `items: List<MiuixGlassNavigationItem>`、`selectedIndex`、`onSelect` | `backdrop`、`visible: true`、`height: 54`；不是旧组件的 `children`，没有旧栏的 2..5 项断言 |
| `MiuixGlassNavigationItem` | `icon: Widget` | `label`、`contentDescription`；矢量数据先用 `MiuixIcon(vector: ...)` 包装 |
| `MiuixGlassTabRow` | `tabs: List<String>`、`selectedIndex`、`onSelect: ValueChanged<int>?` | `backdrop`、`surfaceAlpha: 1`、`height: 40`、`tabGap: 12`、`colors`；`onSelect: null` 禁用 |
| `MiuixGlassSegmentedTabRow` | 同上 | 连体轨道；`height: 40`、`trackColor`、`indicatorColor`、`selectedContentColor`、`contentColor`；没有 `colors` 或 `tabGap` 参数 |
| `MiuixGlassPopup` | `show`、`onDismissRequest`、`child`，并提供 `anchor` 或 `anchorBounds` | 普通固定角展开；不传 Kotlin 的 `secondary` 参数，二级用独立组件 |
| `MiuixGlassTransformPopup` | `show`、`onDismissRequest`、`child`、`anchor`、`anchorContent: Widget` | `simplified`、`stacked`、`maskColor`、`gap`；不接受 `anchorBounds` 替代 `anchor` |
| `MiuixGlassSecondaryPopup` | `show`、`onDismissRequest`、`child`，并提供 `anchor` 或 `anchorBounds` | `materialAnchor` 共享一级菜单的材质；位置需使用一级菜单缩小前的行边界 |
| `MiuixGlassDropdownPopup` | `show`、`onDismissRequest`、`child`，并提供 `anchor` 或 `anchorBounds` | 用于设置行的弧线下拉；可用 `MiuixGlassPopupItem(selected: ...)` 表示当前选项 |
| `MiuixGlassPopupItem` | `text`、`onPressed: VoidCallback?` | `icon: Widget?`、`summary`、`enabled`、`selected`、`showArrow`、`arrowRotation`（角度制）；不是旧 `MiuixDropdownItem(onClick: ...)` |
| `MiuixGlassDialog` | `visible`、`onDismissRequest`、`child` | 不是 `show/content`；默认圆角 28、最大宽 420、边距 24；可配置 `scrimAlpha` |

四种 Glass Popup 共用 `backdrop`、`sizing`、`visuals`、`cornerRadius`、`contentPadding`、
`onDismissFinished`、`onMeasured: ValueChanged<Size>?`。对话框支持其中的样式/尺寸配置和关闭回调，但没有锚点或 `onMeasured` 参数。

- `MiuixGlassPopupSizing(minWidth: 200, maxWidth: 288, maxHeight: 416, safeMargin: 12)`：
  宽高范围仍受安全区/键盘限制。不要将 `maxHeight` 直接传给 Glass Popup。
- `MiuixGlassPopupVisuals(style: ..., material: ..., containerColor: ..., alpha: 1, stroke: ..., showStroke: true, shadow: ...)`：
  `stroke: null` 会选择默认描边，**关掉描边要用 `showStroke: false`**；`shadow: null` 关闭阴影。
  Dialog 默认无描边，仿生材质不额外叠加菜单的 MaterialToken。
- `MiuixGlassPanel` / `MiuixGlass` 的必填项只有 `child`；常用 `backdrop`、`style`、`material`、
  `shape: MiuixGlassShape(...)`、`alpha`、`fill`、`stroke`、`shadow`、`shading`、`enabled`。
  `shape` 不是任意 ShapeBorder；使用 `MiuixGlassShape(cornerRadius: 24, smoothing: 1, borderRadius: ...)`。
- 默认主题预设用 `MiuixGlassDefaults.style(context)`；手动选择材质用
  `MiuixGlassMaterials.puredThinGlass(isDark)` / `popupViewGlass(isDark)`，参数是 bool，不是 BuildContext。
- 菜单内容内部已滚动，通常传 `Column(mainAxisSize: MainAxisSize.min, children: ...)`，
  不要在无界高度中使用 `Expanded` / `Spacer`。标签/导航放在有界宽度中；嵌入 Row 时用 Expanded 或 SizedBox 限宽。

## 背景采样（重要）

玻璃必须采样**不包含自己**的背景子树。使用现有的 MiuixLayerBackdropCapture，foreground 与 capture 为兄弟节点。不能用 capture 包住采样同一 backdrop 的 MiuixGlass，否则形成反馈循环。

~~~dart
final backdrop = MiuixLayerBackdrop(); // 在 State 中持有，dispose 时释放

Stack(
  children: [
    Positioned.fill(
      child: MiuixLayerBackdropCapture(
        backdrop: backdrop,
        child: const ColoredBox(color: Color(0xFF687AC8)),
      ),
    ),
    Center(
      child: SizedBox(
        width: 240,
        height: 140,
        child: MiuixGlassPanel(
          backdrop: backdrop,
          style: MiuixGlassStyles.commonSmallThin,
          shape: const MiuixGlassShape(cornerRadius: 32),
          stroke: MiuixGlassStrokes.middleLight,
          child: const Center(child: Text('OS4 Glass')),
        ),
      ),
    ),
  ],
)
~~~

- 仿生玻璃使用 GlassStyle 的折射、反射、色调、内光和方向光；35 组源端参数见 MiuixGlassStyles.values。
- 栏和菜单使用 MiuixGlassMaterial：高斯模糊 + 至多三层独立混色，且 shading=false。不要给它们额外叠加仿生玻璃着色。
- MiuixGlassMaterials 提供 puredThinGlass / popupViewGlass / actionBarMask 的深浅色版本，包含 PlusDarker 等九种源端混色模式。
- 顶栏子控件继承父遮罩与子材质组合后的 44.72 / 63.25 逻辑像素模糊，而不是重复截取已经含有自己的画面。
- 没有 backdrop、尚无快照或 shader 不可用时回退到实色；这不是系统级实时模糊。底层快照通常有一帧延迟。
- 可提前 await MiuixGlassRendering.load() 预热 shader；程序共享，FragmentShader 和缓存图像随渲染节点释放。不新增第三方依赖。

## 顶栏、标签、导航

- MiuixBlurTopAppBar 保留原滚动行为，通过 largeTitleBlurRadius（默认 12）增加大标题折叠模糊，titleAlpha 同时控制大、小标题及副标题。
- MiuixGlassTopAppBar 的操作区放 MiuixGlassIconButton。配合 MiuixScrollBehaviorListener(behavior: behavior, ...) 和 scrollBehavior。
- 建议显式传 `isContentScrolled`，监听 ScrollController 并在“离开/回到顶部”时重建，不能只在初次 build 读取一次 offset。页面回顶时，即使大标题保持折叠，也能清除材质。
- MiuixGlassTabRow 是分离胶囊：默认高度 40、间距 12；neutralColors 搭配 height:35。MiuixGlassSegmentedTabRow 是连体轨道：高度 40、内部 padding 3、间距 8。
- surfaceAlpha 控制普通填充→玻璃过渡；在玻璃顶栏内部还会乘以共享显隐进度。
- MiuixGlassNavigationBar 最小高度 54，支持双行标签、RTL、按下即选择与跨项拖拽。拖动尾缘上限是 **60 物理像素**，不是 60dp。
- 选择索引和 visible/show 均为受控属性；onSelect 需要更新父组件状态。尊重 MediaQuery.disableAnimations。

## 完整接线示例

以下示例可作为支持 OS4 版本的 `main.dart`。它只在 content 内捕获普通列表，玻璃顶栏/底栏和菜单在捕获树外；
保留同一滚动行为与锚点，并在销毁时释放。标签栏可替换为 `MiuixGlassSegmentedTabRow`，但要移除独立标签专用参数。
菜单通过 `onDismissFinished` 等退场完成后再打开对话框，避免两个弹层抢焦点。

~~~dart
import 'package:flutter/material.dart';
import 'package:flutter_miuix/miuix.dart';

void main() => runApp(
  MiuixSystemTheme(
    child: Builder(
      builder: (context) {
        final theme = MiuixTheme.of(context);
        return MaterialApp(
          theme: ThemeData(
            brightness: theme.brightness,
            colorScheme: ColorScheme.fromSeed(
              seedColor: theme.colors.primary,
              brightness: theme.brightness,
            ),
          ),
          home: const Os4SkillDemo(),
        );
      },
    ),
  ),
);

class Os4SkillDemo extends StatefulWidget {
  const Os4SkillDemo({super.key});
  @override
  State<Os4SkillDemo> createState() => _Os4SkillDemoState();
}

class _Os4SkillDemoState extends State<Os4SkillDemo> {
  final _backdrop = MiuixLayerBackdrop();
  final _scroll = ScrollController();
  final _behavior = MiuixExitUntilCollapsedScrollBehavior();
  final _menuAnchor = MiuixGlassPopupAnchor();
  bool _scrolled = false, _menuOpen = false, _dialogOpen = false;
  bool _openDialogAfterMenu = false;
  int _tab = 0, _destination = 0;

  @override
  void initState() {
    super.initState();
    _scroll.addListener(_updateOverlap);
  }

  void _updateOverlap() {
    final scrolled = _scroll.hasClients && _scroll.offset > 0;
    if (scrolled != _scrolled) setState(() => _scrolled = scrolled);
  }

  @override
  void dispose() {
    _scroll.removeListener(_updateOverlap);
    _scroll.dispose();
    _behavior.state.dispose();
    _menuAnchor.dispose();
    _backdrop.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final colors = MiuixTheme.of(context).colors;
    return Material(
      color: colors.surface,
      child: Stack(
        children: [
          MiuixScaffold(
            topBar: MiuixGlassTopAppBar(
              title: 'OS4 demo',
              backdrop: _backdrop,
              scrollBehavior: _behavior,
              isContentScrolled: _scrolled,
              actions: [
                MiuixGlassIconButton(
                  anchor: _menuAnchor,
                  onPressed: () => setState(() => _menuOpen = true),
                  tooltip: 'Open menu',
                  child: const Icon(Icons.more_horiz),
                ),
              ],
              bottomContent: Padding(
                padding: const EdgeInsets.all(12),
                child: MiuixGlassTabRow(
                  tabs: const ['Overview', 'Details'],
                  selectedIndex: _tab,
                  onSelect: (i) => setState(() => _tab = i),
                ),
              ),
            ),
            bottomBar: SafeArea(
              top: false,
              child: Padding(
                padding: const EdgeInsets.all(12),
                child: MiuixGlassNavigationBar(
                  backdrop: _backdrop,
                  selectedIndex: _destination,
                  onSelect: (i) => setState(() => _destination = i),
                  items: [
                    const MiuixGlassNavigationItem(
                      icon: Icon(Icons.home_outlined),
                      label: 'Home',
                    ),
                    MiuixGlassNavigationItem(
                      icon: MiuixIcon(vector: MiuixIcons.os4.settings),
                      label: 'Settings',
                    ),
                  ],
                ),
              ),
            ),
            content: (padding) => MiuixLayerBackdropCapture(
              backdrop: _backdrop,
              child: ColoredBox(
                color: colors.surface,
                child: MiuixScrollBehaviorListener(
                  behavior: _behavior,
                  child: ListView(
                    controller: _scroll,
                    padding: padding,
                    children: [
                      MiuixText('Tab $_tab / Destination $_destination'),
                      for (var i = 0; i < 30; i++)
                        Padding(
                          padding: const EdgeInsets.all(16),
                          child: MiuixText('Row $i'),
                        ),
                    ],
                  ),
                ),
              ),
            ),
          ),
          MiuixGlassTransformPopup(
            show: _menuOpen,
            anchor: _menuAnchor,
            backdrop: _backdrop,
            simplified: true,
            anchorContent: const Center(child: Icon(Icons.more_horiz)),
            onDismissRequest: () => setState(() => _menuOpen = false),
            onDismissFinished: () {
              if (!mounted || !_openDialogAfterMenu) return;
              setState(() {
                _openDialogAfterMenu = false;
                _dialogOpen = true;
              });
            },
            child: MiuixGlassPopupItem(
              text: 'About OS4',
              onPressed: () => setState(() {
                _openDialogAfterMenu = true;
                _menuOpen = false;
              }),
            ),
          ),
          MiuixGlassDialog(
            visible: _dialogOpen,
            backdrop: _backdrop,
            onDismissRequest: () => setState(() => _dialogOpen = false),
            child: Column(
              mainAxisSize: MainAxisSize.min,
              children: [
                const MiuixText(
                  'Opt-in glass; original widgets are unchanged.',
                ),
                MiuixButton(
                  onPressed: () => setState(() => _dialogOpen = false),
                  child: const Text('Close'),
                ),
              ],
            ),
          ),
        ],
      ),
    );
  }
}
~~~

## 按钮变形成菜单

~~~dart
final menuAnchor = MiuixGlassPopupAnchor(); // State 字段；dispose 时释放
bool menuOpen = false;

// 触发按钮：不要再给同一 anchor 套一个 MiuixGlassAnchor。
MiuixGlassIconButton(
  anchor: menuAnchor,
  onPressed: () => setState(() => menuOpen = true),
  child: const Icon(Icons.more_horiz),
)

// 始终挂载，切换 show；退出动画结束后才移除 Overlay。
MiuixGlassTransformPopup(
  show: menuOpen,
  anchor: menuAnchor,
  backdrop: backdrop,
  simplified: true,
  anchorContent: const Center(child: Icon(Icons.more_horiz)),
  onDismissRequest: () => setState(() => menuOpen = false),
  child: Column(
    mainAxisSize: MainAxisSize.min,
    children: [
      MiuixGlassPopupItem(
        text: '新建',
        onPressed: () => setState(() => menuOpen = false),
      ),
    ],
  ),
)
~~~

普通控件或设置行用 MiuixGlassAnchor(anchor: ..., child: ...) 绑定。也可直接传 anchorBounds（**全局窗口坐标**），弹层会转换到自己的坐标系。

- anchorContent 是触发控件内容的副本，不能复用 GlobalKey。
- 弹窗默认宽 200–288、高不超过 416、窗口边距 12、圆角 24。长内容内部滚动；安全区与软键盘进一步限制可用尺寸。
- 二级菜单打开前保存触发行的 anchor.bounds，再将一级菜单 stacked 设为 true。二级传 materialAnchor: primaryAnchor 共享材质。不要在一级菜单缩小后重新测量触发行。
- 可把包含一级菜单的独立捕获层传给二级菜单的 backdrop，以采样被模糊的一级菜单；避免自采样。没有该独立层时只采样已有页面背景。
- 支持 Escape、路由返回、Android 预测性返回的预览/取消/完成；二级菜单为最顶层时优先处理。
- 关闭期间不再接受菜单操作，退出完成后清理遮罩、返回记录与锚点隐藏状态。onDismissFinished 在退场结束时回调。
- MiuixGlassPopupVisuals 可覆盖材质、阴影、颜色；showStroke:false 关闭高光。对话框默认居中、圆角 28、深浅遮罩 0.6/0.3。

## 旧菜单接入

MiuixOverlayCascadingListPopup、MiuixWindowCascadingListPopup，以及两种 IconCascadingDropdownMenu 均增加可选 surfaceBuilder。原调用无需修改：

~~~dart
surfaceBuilder: miuixGlassSurface(backdrop: backdrop),
~~~

该入口只替换面板材质，保留旧菜单的交互与动画；需要 OS4 变形开场时使用新的 GlassTransformPopup / GlassSecondaryPopup。底层 MiuixListPopupContent 与两种 ListPopup 宿主也支持该构建器。

~~~dart
MiuixIcon(vector: MiuixIcons.os4.search)
~~~

## 生成与验证

~~~text
node tool/gen_os4_assets.mjs
node tool/gen_os4_icons.mjs
flutter analyze
flutter test
~~~

上述生成命令仅供组件库维护者在 flutter_miuix 仓库内运行，不是安装 skill 后使用组件的前置步骤。
生成器默认读取本项目 demo/miuix，可通过 --source=<上游路径> 指定其他检出。当前六个 GLSL shader 来自上游 AGSL/SkSL 的 SDF、折射、混色、描边、阴影和边缘光；不依赖 Android 私有 API。

示例首页新增「HyperOS 4 · Glass」，提供材质选择、两类标签、悬浮导航、全部弹窗和图标搜索。渲染测试在 Skia 测试引擎执行；Android/iOS 真机 Impeller、平台字体与系统返回手势仍需设备验收。
